# Bazy danych

Materiały do bezpiecznego i uporządkowanego przechowywania informacji.

## Proponowana kolejność

1. Rekordy, tabele, kolumny i klucze.
2. Podstawowe zapytania SQL: `SELECT`, `INSERT`, `UPDATE`, `DELETE`.
3. Filtrowanie, sortowanie i agregowanie danych.
4. Relacje między tabelami i klucze obce.
5. Połączenie aplikacji z bazą oraz kopie zapasowe.

Ćwicz na przykładowych, nieprywatnych danych.
