# Sieci komputerowe

Podstawy komunikacji między urządzeniami i usługami.

## Proponowana kolejność

1. Klient, serwer, router i pakiet danych.
2. Adres IP, port, DNS i nazwy domenowe.
3. HTTP i HTTPS: żądanie, odpowiedź, nagłówki i statusy.
4. Podstawy lokalnej diagnostyki połączenia.
5. Zasady prywatności i bezpiecznego korzystania z sieci.

Eksperymentuj wyłącznie z usługami i systemami, do których masz upoważniony dostęp.
