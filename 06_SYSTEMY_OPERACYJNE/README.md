# Systemy operacyjne

Materiały o tym, jak system zarządza programami, plikami i urządzeniami.

## Proponowana kolejność

1. Pliki, katalogi, ścieżki i rozszerzenia.
2. Procesy, pamięć i uprawnienia.
3. Podstawowe polecenia terminala w używanym systemie.
4. Zmienne środowiskowe i uruchamianie programów.
5. Instalowanie narzędzi i izolowanie zależności projektu.

Przed wykonaniem polecenia sprawdź, jaki zakres plików lub procesów ono obejmuje.
