# Plan nauki

Plan prowadzi od podstaw do samodzielnego, małego projektu. Tempo można dostosować — ważne jest opanowanie umiejętności, a nie liczba dni.

## Etapy

| Etap | Zakres | Efekt pracy |
|---|---|---|
| 1. Pierwszy program | Uruchamianie Pythona, `print()`, komentarze | Program wyświetlający własny komunikat |
| 2. Dane i obliczenia | Zmienne, typy danych, konwersje, operatory | Prosty kalkulator lub podsumowanie danych |
| 3. Sterowanie programem | Warunki, pętle, funkcje | Program reagujący na dane użytkownika |
| 4. Podstawy informatyki | Matematyka, logika i algorytmika | Rozpisany i zaimplementowany algorytm |
| 5. Narzędzia i dane | System operacyjny, terminal, bazy danych, sieci | Mały program zapisujący i odczytujący dane |
| 6. Jakość oprogramowania | Projektowanie, testowanie, dokumentowanie | Uporządkowany projekt z testami |
| 7. Projekt końcowy | META-GENIUSZ CITY | Działający prototyp opisany w dokumentacji |

## Kolejność nauki Pythona

Przechodź przez katalogi w podanej kolejności:

1. `001_PIERWSZY_PROGRAM`
2. `002_ZMIENNE`
3. `003_TYPY_DANYCH`
4. `004_OPERACJE`
5. `005_WARUNKI`
6. `006_PETLE`
7. `007_FUNKCJE`

W każdym etapie:

1. Przeczytaj notatki i przykłady.
2. Uruchom kod i opisz własnymi słowami, co robi.
3. Wykonaj ćwiczenia bez kopiowania gotowego rozwiązania.
4. Uruchom testy, jeśli są dostępne, i popraw błędy.
5. Zapisz w dzienniku rezultat oraz następny krok.

## Proponowany rytm

- 3–5 sesji tygodniowo po 30–60 minut.
- Na początku sesji przypomnij sobie poprzedni temat.
- Po każdej większej części zbuduj mały program wykorzystujący kilka poznanych elementów.
- Raz w tygodniu przejrzyj dziennik i wybierz konkretny cel na kolejny tydzień.

## Kryterium ukończenia etapu

Etap jest ukończony, gdy potrafisz wyjaśnić kluczowe pojęcia, samodzielnie wykonać ćwiczenie bez instrukcji krok po kroku i sprawdzić wynik. Do samooceny używaj [systemu JSK](SYSTEM_OCENY_JSK.md).
