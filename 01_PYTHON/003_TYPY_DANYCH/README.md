# 003 — Typy danych

## Cele

- rozróżniać `str`, `int`, `float` i `bool`;
- sprawdzać typ wartości za pomocą `type()`;
- konwertować dane funkcjami `int()`, `float()` i `str()`;
- rozumieć, że tekst `"5"` i liczba `5` są różnymi wartościami.

## Ćwiczenie

Zbuduj krótką kartę mieszkańca miasta, zawierającą tekst, wiek oraz informację logiczną.
