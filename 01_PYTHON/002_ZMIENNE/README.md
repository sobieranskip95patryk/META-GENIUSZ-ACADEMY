# 002 — Zmienne

## Cele

- przypisywać wartości do nazw, np. `miasto = "META-GENIUSZ CITY"`;
- odczytywać i aktualizować wartości zmiennych;
- używać nazw, które wyjaśniają znaczenie danych;
- wyświetlać zmienne za pomocą `print()` i f-stringów.

## Ćwiczenie

Utwórz zmienne opisujące nazwę projektu i liczbę jego mieszkańców, a następnie wyświetl podsumowanie.
