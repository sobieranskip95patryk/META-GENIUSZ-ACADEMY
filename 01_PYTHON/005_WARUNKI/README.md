# 005 — Warunki

## Cele

- podejmować decyzje za pomocą `if`, `elif` i `else`;
- zapisywać porównania, takie jak `==`, `!=`, `<` i `>=`;
- łączyć warunki i uwzględniać przypadki graniczne;
- testować różne gałęzie programu.

## Ćwiczenie

Przygotuj prostą regułę, która na podstawie danych wejściowych wybierze komunikat dla mieszkańca META-GENIUSZ CITY.
