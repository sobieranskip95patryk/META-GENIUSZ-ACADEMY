# 004 — Operacje

## Cele

- wykonywać dodawanie, odejmowanie, mnożenie i dzielenie;
- poznać dzielenie całkowite `//`, resztę z dzielenia `%` i potęgowanie `**`;
- porównywać wartości i łączyć warunki operatorami `and`, `or`, `not`;
- stosować nawiasy i rozumieć kolejność działań.

## Ćwiczenie

Napisz kalkulator powierzchni prostokąta i sprawdź wynik dla kilku zestawów danych.
