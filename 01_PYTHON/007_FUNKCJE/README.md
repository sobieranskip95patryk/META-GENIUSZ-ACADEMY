# 007 — Funkcje

## Cele

- definiować funkcje za pomocą `def`;
- przekazywać argumenty i zwracać wynik przez `return`;
- rozróżniać wypisywanie wyniku od zwracania wartości;
- dzielić program na mniejsze, czytelne części.

## Ćwiczenie

Zamknij wybrane obliczenie z poprzednich lekcji w funkcji, a następnie wywołaj ją dla kilku danych.
