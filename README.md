# META-GENIUSZ ACADEMY

Repozytorium do nauki programowania i informatyki od podstaw. Nauka prowadzi od pierwszego programu w Pythonie, przez fundamenty informatyki, do projektu **META-GENIUSZ CITY**.

## Jak zacząć

1. Zainstaluj Python 3.
2. Otwórz terminal w katalogu repozytorium.
3. Uruchom pierwszą lekcję:

   ```powershell
   python 01_PYTHON\001_PIERWSZY_PROGRAM\lekcja_001.py
   ```

4. Uruchom test lekcji:

   ```powershell
   python -m unittest discover -s 01_PYTHON\001_PIERWSZY_PROGRAM -p "test_*.py" -v
   ```

Przechodź przez lekcje po kolei. Najpierw spróbuj wykonać zadania samodzielnie, a dopiero potem sprawdź wynik. Zapisuj postępy w [dzienniku](00_DOKUMENTACJA/DZIENNIK_POSTEPOW.md).
