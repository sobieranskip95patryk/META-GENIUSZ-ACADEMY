# Logika i algorytmika

Nauka precyzyjnego opisywania problemów i projektowania kroków prowadzących do rozwiązania.

## Proponowana kolejność

1. Instrukcje, warunki logiczne i tabele prawdy.
2. Opis problemu: dane wejściowe, wynik i ograniczenia.
3. Algorytmy krok po kroku, pseudokod i schematy blokowe.
4. Wyszukiwanie i sortowanie na małych przykładach.
5. Testowanie przypadków typowych, brzegowych i błędnych.
6. Szacowanie liczby kroków algorytmu.

Przed implementacją opisz algorytm własnymi słowami lub pseudokodem.
